---
name: HostelX full account reset
description: Scope for returning every HostelX account to first-time setup.
---

For a full HostelX reset, clear all residents' display names, display IDs, bios, and profile-photo references, including the Owner's seeded display name. Keep permanent `userN.hostelx.in` login IDs and roles, preserve chats/messages, and revoke active sessions.

**Why:** The user chose first-time setup for every account; keeping the seeded Owner display name would conflict with that choice.

**How to apply:** When performing another all-account reset, restore every account to pending setup and clear all profile fields without removing roles, chats, or messages.
